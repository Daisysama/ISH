# FromISH · 项目入口、个人资料、提醒与公告精简（2026-09-12）

## 背景与产品决定

「我的项目」已有顶部按钮、集中选择项目模块及项目卡片三套发动态入口。保留项目卡片右侧的「发动态」，其他两套撤去，使操作和所选项目始终相邻。兴趣推断文案删去一个「死」字。用户希望收藏有新动态时被告知、评论互动能从通知精确抵达、用户名可进入资料页、公告操作紧贴对应公告并能置顶。管理界面的颜色需要文字示例，不把未审举报视作劣迹。

## 改动文件与职责

- `src/app/dashboard/page.tsx`、`src/frontend/components/profile/ProfileForm.tsx`：移除重复入口、修改一句话，保留项目卡片的就近动作。
- `src/backend/updates/favorite-notices.ts`、`src/backend/updates/actions.ts`、`src/backend/updates/queries.ts`、`src/app/projects/[id]/updates/page.tsx`：在自动公开或人工审核通过的同一事务内，按收藏关系写一次站内提醒；通知链接仍能定位 50 条之外的历史公开动态。作者不会因为收藏自己而收到重复提醒；通知 sourceKey 防重复。
- `src/backend/comments/links.ts`、`src/backend/comments/actions.ts`、`src/backend/comments/governance.ts`、`src/app/projects/[id]/discussion/page.tsx`：新评论与回复无论立即公开还是人工放行，提醒统一使用带目标 ID 的链接。服务端核对项目、动态、可见性、主评论所在分页，然后定位；消息入口的返回回到消息页。禁止通过链接读取未审核他人的评论。
- `src/backend/profile/public-queries.ts`、`src/app/users/[id]/page.tsx`：公开用户名资料；本人明确选择后才展示自填介绍、技能、经历、作品链接和当前公开同行；不公开邮箱、兴趣推断、移出历史及非公开项目。游戏测试暂由本人自填经历展示，未建立已验证的测试记录。
- `src/core/profile/user-profile.ts`、`src/backend/profile/actions.ts`、`src/backend/profile/queries.ts`、`src/frontend/components/profile/ProfileForm.tsx`：增加公开个人资料的自愿开关，默认关闭，避免把过去私下填写的画像自动公开；本人可随时关闭。
- `src/backend/projects/queries.ts`、`src/frontend/components/projects/ProjectCard.tsx`、`src/frontend/components/comments/CommentThread.tsx`、`src/app/projects/[id]/page.tsx`、`src/app/projects/[id]/team/page.tsx`：项目发起人、评论作者及团队成员有可点击资料入口。
- `src/shared/user-navigation.ts`：资料页只接受白名单站内返回地址，保留从项目卡、详情、团队和具体评论来时的原路返回，避免开放跳转。
- `prisma/schema.prisma`、`prisma/migrations/20260912233000_profile_reports_announcement_pins/migration.sql`：新增公告置顶时间、公开履历的默认关闭开关、账号举报及事件表；迁移只增加列和表，不擦除已有记录。
- `src/backend/user-reports/actions.ts`、`src/frontend/components/governance/UserReportForms.tsx`、`src/app/users/[id]/report/page.tsx`、`src/app/admin/user-reports/page.tsx`、`src/shared/user-report.ts`：用户举报、本人撤回、网站独立审核、处理结果通知、中文分类与追加审计。举报与转交账号处分不自动生成违规案底；举报人与被举报人不能审自己的案件。具体限制仍走原账号处分和申诉流程。
- `src/backend/announcements/actions.ts`、`src/frontend/components/announcements/AnnouncementForms.tsx`、`src/app/announcements/page.tsx`、`src/app/admin/announcements/page.tsx`：公共页保留「起草并发布公告」，已发布公告右侧独立放编辑、删除、置顶；删除实际撤回公开展示，需理由、保留原文；置顶和取消置顶均写事件，管理员操作通知站主。
- `src/app/admin/users/page.tsx`、`src/app/admin/governance/page.tsx`、`src/app/globals.css`：颜色状态示例、账号举报入口与响应式公告操作区；色彩始终附文本，不自动按未审举报给人定性。

## 权衡与验证边界

当前「推送」是站内消息，不包括邮件、浏览器或手机系统推送。置顶排序只对已发布公告生效，编辑公开版仍需理由；被撤回公告显示回执但不能重新置顶。举报审查只产生独立记录，要做账号处罚仍需另一个操作。历史画像默认不公开；用户自主开启后最多显示 30 个公开发起 / 同行项目，完整测试履历待后续结构化功能。

本轮验证 Prisma schema、生成客户端、TypeScript、生产构建和增量补丁试应用；当前执行环境没有用户的数据库与 Windows PowerShell，因此新迁移及多账号通知、回避与实际返回路径仍需在本机联调。切勿用 `db push`、重置数据库或覆盖未提交文件解决迁移冲突。
