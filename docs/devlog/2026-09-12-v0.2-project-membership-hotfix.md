# v0.2 Project Membership missing-files hotfix

日期：2026-09-12

## 做了什么

- 补回 `src/backend/memberships/queries.ts`。
- 补回 `20260912143000_project_memberships` migration。
- 保留已经接受的历史响应，并在 migration 中回填为 ACTIVE 项目同行关系。

## 为什么改

Project Membership 功能包已经修改了 Prisma schema、Dashboard 和项目详情页，并引用了
`@/backend/memberships/queries`，但打包 Patch 时漏掉了这个新文件和对应 migration。
因此进入“我的项目”会触发 Next.js `Module not found`，数据库也尚未真正建立
`project_memberships` 表。

## 思路与权衡

- 不回滚已经完成的 Membership 页面逻辑，而是补齐缺失依赖。
- 响应历史不作为长期权限凭证；只有 ACTIVE `ProjectMembership` 代表当前同行身份。
- 历史 APPROVED 响应自动迁移，避免测试账号升级后丢失已经建立的同行关系。
- 新同行者仍默认 `permissions=[]`，不做时间到期自动授权。
