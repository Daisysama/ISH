# 2026-09-12 · v0.2 FromISH Alpha Visual Pass

## 本次目标

在已经验收通过的“咩 → 待审核 → 管理员审核 → 发布”业务闭环上，建立 FromISH 第一套可公开展示的产品视觉语言。

本阶段不改变核心审核与发布规则，重点解决“网站能用，但还不像 FromISH”的问题。

## 视觉方向

- 暖白主背景，保留呼吸感；
- 深绿作为主要交互色；
- 暖金只用于光、Alpha 临时标识和少量点睛，不把产品做成黑金奢侈品；
- 用晨光、太阳、路径和留白表达“开始 / 同行 / 作品正在长大”；
- 使用“灵光初现 / First Glimpse”弃稿中的抽象线形星芒作为 FromISH Alpha Mark：网站使用浅底版，社交媒体预留深底版；伊始蛋与正式“灵光一闪”继续不公开。

## 文案原则

新增 `docs/product/COPYWRITING_PRINCIPLES.md`，确立：

> 功能必须清楚，但表达不必无聊。

主要产品文案调整：

- “有个想法？找人一起把它做出来。” → “有点子？上伊始！找乐子？也上伊始！”；
- “正在发生的项目” → “羊群广场 / 加入羊群，一起追逐太阳！”；
- 母品牌内部口号“没有牧羊人，只有同行者。”退出产品主导航。

## 工程实现

- 新增 `src/frontend/styles/tokens.css`：统一视觉 token；
- 新增 `BrandIdentity` 与 `PublicNav`：统一公共品牌与导航；
- 新增 `ProjectCard`：统一公开项目卡片；
- 新增 `public/brand/fromish-alpha-mark.png`：网站浅底 Alpha Mark；
- 新增 `public/brand/fromish-alpha-social.png`：社交媒体深底 Alpha Mark；
- 新增 `src/app/icon.png`：网站 favicon / app icon，沿用浅底 Alpha Mark；
- 首页由重定向页升级为真正的 FromISH 公共入口；
- 登录、注册、羊群广场、项目详情、咩表单、Dashboard 统一视觉语言；
- 管理员审核页保持克制，以功能清晰优先。

## 明确不做

本 Visual Pass 不伪造尚不存在的能力：

- 不加入假的搜索；
- 不加入假的筛选；
- 不显示假的点赞、评论、用户量或项目量；
- 不添加没有后端实现的“关注 / 收藏 / 申请加入”等按钮。

## 验收要求

完成后至少重新验证：

1. `npm run typecheck`；
2. `npm run build`；
3. 注册 / 登录；
4. 咩一个项目；
5. 管理员审核；
6. 发布后在羊群广场可见；
7. 未发布项目仍保持访问控制；
8. 桌面和窄屏布局没有明显破版。

## 后续方向

Visual Pass 完成并验收后，再评估加入：项目封面、标签、搜索、申请加入、玩家反馈与制作人回复。任何新增能力必须先有真实后端闭环，再进入 UI。

## Alpha Mark 资源校正

UI 现场验收时发现，网站 Header 使用的浅底 Alpha Mark 来自此前的裁切版本，
图形在方形容器中的比例过小，实际显示时容易看成一个细小符号，和确定的 Alpha Mark 原稿不一致。

本次将网站浅底 Alpha Mark 与 favicon 直接替换为已确认的原始方形版本，
并移除 Header 中额外的 `scale()` 处理，避免二次裁切和比例漂移。

本次只校正品牌资源呈现，不调整已验收的业务逻辑，也暂不继续修改首页背景图片。
后续背景与氛围图将由产品侧提供明确素材后再逐页替换和细化。

## 登录 / 注册场景视觉收口与交互原则补充

现场验收发现认证页面左侧曾使用 Alpha Mark 作为大面积低透明度装饰。虽然不影响功能，但会形成重复品牌曝光并抢占主视觉注意力。

本次不移除现有 `auth-landscape-glow` 结构，而是将其从 Logo 图片替换为纯 CSS 的柔和径向光晕：

- 保留晨光与空间层次；
- 不再在天空区域重复展示 Logo；
- 不改变登录 / 注册页面结构与业务逻辑；
- 后续正式背景素材确定后，可继续替换氛围层而不影响表单。

同时在产品文案规范中加入“平台要懂人，但别烦人”原则，明确渐进式画像和偏好学习应优先减少打扰。
