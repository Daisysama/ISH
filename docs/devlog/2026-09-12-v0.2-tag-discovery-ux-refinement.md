# v0.2 标签、推荐与发现体验收口

日期：2026-09-12

## 做了什么

- 将官方标签体系从六组压缩为四组：类型与玩法、游玩方式、题材与风格、关系与受众。
- 扩充 JRPG、CRPG、二次元、二游 / 二次元手游、国风、古风、武侠、仙侠、魂Like 等常用标签。
- “为你推荐”统一为“为您推荐”，并让明确喜欢标签的重合数量直接影响排序优先级。
- 羊群广场说明改为“想看点子、Demo、试玩邀请，还是找羊同行？按您喜欢的方式逛！”。
- “咩一个”入口主文案改为“请把您的梦，咩出来！”。
- 清理用户可见文案中的“你”，统一为“您”或自然省略人称。
- 将“隐藏项目”从“不感兴趣”里彻底拆出，作为独立、可恢复的用户控制项。
- 去掉登录 / 注册氛围背景里造成“掉色块”观感的叠加层，并改成更稳定的暖色渐变。

## 为什么改

“低下限、高上限”不仅适用于发布项目，也适用于推荐与发现。用户可以不填画像、不回答追问，但始终应保留隐藏、恢复、调整偏好的控制权。推荐可以个性化，管理员监管则必须保持全量视野。

标签分类不应要求用户理解内部理论边界。“机制与体验”与“类型与玩法”在真实游戏社区里高度重叠，因此合并，减少选择成本。

## 关键取舍

- “不感兴趣”不等于“隐藏”，两者数据库关系也分离。
- 隐藏前轻量确认，隐藏后可立即撤销，并可在画像页恢复。
- 关闭偏好追问只减少打扰，不会关闭隐藏能力。
- 推荐优先级首先看用户明确表达的喜欢标签重合；系统推断继续保持弱信号。
- 未建立推荐画像时，不向用户展示没有意义的“为您推荐”排序。
