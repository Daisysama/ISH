# 下一阶段 · 媒体资料与可信账号

本轮先完成公开评论、互动消息、公开用户资料与公告位置调整；以下方向作为下一阶段设计输入，不代表已经上线。

1. 图片基础：头像上传及审核、咩与项目作品图片、一张可选封面图；按上传者、作品和项目分别保留版权/授权信息与内容审查记录。未经审核不公开，隐藏与撤回保留处置依据。
2. 评论区图片与更先进文本审核：在评论文字规则之外增加图片检测、人工纠错、举报与独立申诉；维护错误拦截样例、审核等待时间和复核日志。
3. 账号验证：邮箱验证码、可选手机验证码，结合防机器人滥用方案；在真实公网开放注册前落实限流及安全校验，不能用测试环境的弱保护冒充生产状态。
4. 公开参与履历：有可核查的项目活动与测试记录后，让用户自主决定展示范围；未验证经历保留「本人填写」标识，不泄露退出/移除历史。
5. 项目 BGM 探索：制作人从已取得许可的曲目中选择，展示来源与授权范围，提供音量、暂停和记住用户选择的控件；不把听觉刺激强加给访问者。

组织顺序：先完善图片与审核，再做账号验证/防滥用和受控公网联调；内部论坛、任务、投票按现有路线图继续后置。
